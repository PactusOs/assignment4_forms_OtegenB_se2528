Five pages for the Web assignment. All pages use one CSS file (`css/style.css`) and Bootstrap stored locally.

| Page | Task |
| --- | --- |
| `index.html` | Task 0: simple contact form |
| `task1.html` | Task 1: validation |
| `task2.html` | Task 2: Bootstrap forms and grid |
| `task3.html` | Task 3: Bootstrap validation feedback |
| `task4.html` | Task 4: registration form with validation |

## How to run

1. Open the `assignment4_forms` folder in VS Code.
2. Open `index.html` in a browser, or use the VS Code Live Server extension.
3. Use the navbar to switch between tasks.
4. Try empty fields, incorrect email formats, short text, mismatched passwords and the Reset button.

Bootstrap is included in `css/bootstrap.min.css` and the website works offline. The JavaScript file is `js/script.js`. Form submissions are validated locally and no information is stored or sent to a server.
